# ClearAI learning hub (alt 2)

A brief, sourced history of AI from 1950 to 2026, written for readers of *analogue by
ClearAI* and laid out as a learning hub: a hub page of article cards grouped by part,
filterable and collapsible, eleven article pages, a glossary and a source list.

```
npm install
npm run dev      # http://localhost:4321
npm test         # data integrity tests
npm run build    # static site in dist/
```

See `CLAUDE.md` for structure and conventions, and `DESIGN.md` for the design tokens.
